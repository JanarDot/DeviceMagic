01

iPhone and iPad

Install from Safari

Add Device Magic to your Home Screen. It opens full-screen with its own app icon.

  1. Open

    Open Device Magic in Safari on your iPhone or iPad.

  2. Share

    Tap Safari's Share button at the bottom of the screen.

  3. Add

    Choose Add to Home Screen, then tap Add.

  4. Cast

    Open the new Device Magic icon and enable browser magic.

02

Android

Download the APK

Install the standalone Android app directly. No Play Store account is needed.

  1. Download

    Tap the APK button below on your Android phone.

  2. Allow

    If Android asks, allow this browser to install unknown apps.

  3. Install

    Tap Install and wait for the confirmation screen.

  4. Cast

    Open Device Magic from your app screen and start casting.
